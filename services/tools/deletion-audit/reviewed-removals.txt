# --- Noisemaker Trigger -> NoisemakerFuse (7 entries) ---
# Reviewed 2026-08-10 (cpdu-jm4). Verified against upstream-spd/master: upstream replaced
# the Trigger buff with NoisemakerFuse extends Fuse and dropped setTrigger/glowing. CPDU
# matches.
#
# Save compatibility was the real question, since the old Trigger extended Buff and was
# persisted via Buff.affect(). Deliberately NOT aliased:
#   - Verified the failure is safe, not a crash. Reflection.forName catches and returns
#     null, and Bundle.get() returns null when the class is unresolvable, so an old save
#     silently drops an in-flight noisemaker trigger rather than failing to load.
#   - An alias would be actively WRONG: Trigger extended Buff and attached to the hero,
#     NoisemakerFuse extends Fuse and attaches to the bomb. Restoring Buff-shaped data
#     into a Fuse would produce a corrupt actor. Dropping is strictly safer.
# Impact is one transient in-run buff on saves made before the change.
Noisemaker#setTrigger(int)
Noisemaker#glowing()
Noisemaker.Trigger#set(int)
Noisemaker.Trigger#act()
Noisemaker.Trigger#storeInBundle(Bundle)
Noisemaker.Trigger#restoreFromBundle(Bundle)
Noisemaker#doPickUp(Hero, int)
